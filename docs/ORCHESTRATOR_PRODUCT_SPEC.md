# Orchestrator Product Spec

Short-term product reality

The orchestrator is still in a proof-oriented reliability phase. It is not yet a general-purpose multi-task autonomous builder.

Short-term goals
- make one-task execution dependable
- make runtime failures diagnosable
- ensure task completion means live-surface completion, not helper-only success
- preserve conservative gates and explicit artifacts

Current sequence
- 157-161: first reliability sprint and re-proof
- 162-165: second reliability sprint and re-proof
